      1. How to use this outliner
        1. Click any line to edit it. Type freely — this is a nested outline, not a flat document.
        2. Click ▸ or ▾ beside a parent to show or hide its children
          1. ⌘→ / ⌘← will do the same
          2. ⌘⌥→ expands this heading’s subheads completely
        3. Keyboard
          1. Enter — new line below (same level, or first child if this line has subheads)
          2. Tab — indent this line under the one above
          3. Shift+Tab — move this line out one level
          4. Promote (⌘[ / Ctrl+[) — lift this line’s children up beside it
          5. Demote (⌘] / Ctrl+]) — pull the following same-level lines under this one
          6. ↑ / ↓ — previous or next line; ⌥↑ / ⌥↓ — same level
          7. !c !d !h !s — insert ♣ ♦ ♥ ♠
          8. A PBN deal line (e.g. N:73.QJT.AQ54.T752 …) gets a suit-diagram child
          9. Backspace at the start of a line — merge with the line above
        4. Expand and collapse
          1. Use View → Expand All / Collapse All for the whole outline
        5. Open and Save
          1. File → Open… / Save — OPML on your computer (re-saves in place when the browser supports it)
          2. Cloud → Open… / Save / Save As… / Delete… — Google Drive outlines after Sign in with Google
          3. Cloud → Copy read-only / editable link — distinct opaque share URLs (not interchangeable)
        6. Edit → Clear Outline removes all lines
        7. Replace these tips with your own outline whenever you are ready.
