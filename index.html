    1. How to use this outliner
      1. Click any line to edit it. Type freely — this is a nested outline, not a flat document.
      2. Keyboard
        1. Enter — new line below (same level, or first child if this line has subheads)
        2. Tab — indent this line under the one above
        3. Shift+Tab — move this line out one level
        4. Promote (⌘[ / Ctrl+[) — lift this line’s children up beside it
        5. Demote (⌘] / Ctrl+]) — pull the following same-level lines under this one
        6. ↑ / ↓ — previous or next line; ⌥↑ / ⌥↓ — same level
        7. !c !d !h !s — insert ♣ ♦ ♥ ♠
        8. A PBN deal line (e.g. N:73.QJT.AQ54.T752 …) gets a suit-diagram child
        9. Backspace on an empty line — delete that line
      3. Expand and collapse
        1. Click ▸ or ▾ beside a parent to show or hide its children
        2. Use View → Expand All / Collapse All for the whole outline
      4. Save and open
        1. File → Import… / Export… — OPML on your computer
        2. File → Open… / Save / Save As… — cloud outlines after Sign in with Google
        3. Copy read-only link — share a view-only URL for a saved cloud outline
      5. Edit → Clear Outline removes all lines
      6. Replace these tips with your own outline whenever you are ready.
